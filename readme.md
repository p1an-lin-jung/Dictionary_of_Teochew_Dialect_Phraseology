## 潮汕方言熟语辞典 OCR 语料库

本仓库为林伦伦-《潮汕方言熟语辞典》OCR 数字化项目，基于原书扫描件进行文字识别、人工校对、结构化清洗，提取潮汕方言熟语（谚语、惯用语、歇后语、俗语）语料。

林伦伦本质是学术商人，在其公众号文章中承认【[为谁辛苦为谁忙——卖书记趣](https://mp.weixin.qq.com/s/nJnHAgTb0X-e2VoGlxdiCw)】，需要卖书赚钱。所以，为了追求著作数量，而忽略质量，书中有非常多的错误（字、音、调等， 2000多条词条里，出现错误估计有200处左右），本仓库进行了人工校对，确保数据质量，如：

* 将1调与5调混用；
* 5调与6调误写；
* 3调与7调混用；
* 受澄海变调影响，将 “□脚翘”的kong3写成kong6；
* 鼻化韵不统一，𱰸有时写mui3，有时写muin3；
* 对闭口韵不太熟，将”脸“写成”liam2“；
* 受国际音标习惯的影响，“涨”标成“tin6”、“隔”标成“kêh4”等。

### 词条格式

每两行作为一个item：

* 第一行以`{}`包括的是原文正文页面，【】包裹的是词条，之后潮拼（汕头市区口音，一般标注原调）；
* 第二行是后面是释义，最后是例句

```
{P 3}【白虾钓狗母】 bêh8 hê5 dion3 gao2 bho2
比喻以小的付出换来大的收入。例：“我个是～，挈无底个来，倒掼着一大堆转来转去。（我这是以虾钓鱼，没拿来什么，倒提了一大包东西西回去。）”
```

部分汉字用复合符号表示： {亻因}、{足忝}、{足甫}、{殳页}

体例：每条词条 → 潮拼 → 释义 → 例句（附带普通话翻译；气象、农谚一般不附例句）
用字原则：从众从俗，优先采用民间约定俗成俗字，不强行使用冷僻本字。




### 凡 例

本辞典所收词条限于潮汕方言中跟普通话不同的、三字以上的熟语。熟语包括惯用语、成语、谚语、格言和歇后语。惯用语与成语都是词组，但惯用语以三字为主（也有一些是三字以上的），结构也不似成语一样紧密，可以拆开来，中间插入一些别的词语；成语以四字为主，结构紧密，通常不拆开使用。谚语和格言都具有句子的形式，本辞典合为一类。歇后语指结构分成前后两个部分，前一部分是比喻或隐语，后一部分是解释的俏皮话。全书共收词条2150多条。

本辞典每个词条都注音、释义。除了农谚、气象谚语之外，大多数词条都举了例句，例句之后加括号翻译为普通话。

本辞典用1960年9月广东省教育行政部门公布的《潮州话拼音方案》注汕头市音。声调只记本调，不记连读变调。正文之后附有国际音标对照的《潮州话拼音方案》，并说明连读变调的规律。读者可以查阅。

本辞典用字以"从众从俗与科学性相结合"为方针，对群众已约定俗成的训读字予以保留，而不用难僻的本字。如用"脚"不用"骹"，用"夜"不用"暝"。群众已普遍使用的方言字，不论有没有本字，一般也予以保留。如"妐（妻子）"、"朥（猪油）"等。多数人已承认了的同音假借字也予以使用，如"阮（我们）"、"卟（掌声）"等。群众认为"有音无字"者，如考出的本字不生僻，则予以使用。如未考出者，则以"□"号表示本字未知，不随意生造。正文之后附有本辞典使用的方言字、同音假借字、训读字表，以便读者参考。

本辞典把全部熟语分成惯用语、成语、谚语（格言）、歇后语四大部分。每部分的词条按首字潮音注音从A至Z排列。首字声韵相同者，则以声调从1至8排列。首字完全同音者，按第二字音序排列。余类推。

本辞典有两个索引：正文之前有《分类词条首字潮音音序索引》，正文之后有《分类词条首字笔画索引》。前者与正文顺序相同；后者以1965年文化部和文改会编印的《印刷通用汉字字形表》为标准，按词条首字笔画从少至多排列。首字笔画数相同者，以笔画"一（丶）"、"│（亅）"、"ノ"、"丶（乀）"、"フ（┐└∟乙）"为序排列。首字完全相同者，则以正文先后顺序排列。
